# WaddleRush browser preview

This is a standalone, fully offline Canvas version of the playable prototype.
It has no package install, server, login, network request, or build step.

## Run

Open `index.html` in Chrome, Edge, Safari, or Firefox. On macOS: Finder →
`WebPreview` → double-click `index.html` (or right-click → Open With → browser).

Press **PLAY**. Drag or click in the arena to steer; hold **BOOST** to dash.
The preview is designed for portrait mobile browsers and works with touch.
